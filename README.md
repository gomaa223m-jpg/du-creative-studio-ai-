# EDU Creative Studio AI — استوديو مستر محمد جمعة التعليمي

منصة تعليمية عربية لإنشاء المحتوى والعروض وأوراق العمل والكتب التفاعلية.

## محرك تأليف الكتب الذكي
يتضمن المشروع Worker آمناً لتوليد مخطوطات الكتب وملء محرر الصفحات، مع بحث عن مصادر ومراجعة علمية أولية.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/gomaa223m-jpg/du-creative-studio-ai-)

بعد النشر، أضف أسرار `OPENAI_API_KEY` و`APP_ACCESS_TOKEN` من إعدادات Worker، ثم اتبع [دليل التفعيل](BOOK_ENGINE_SETUP.md). لا تضع مفاتيح API في ملفات الموقع العامة. استخدام API قد تكون له تكلفة منفصلة.

المراجعة الآلية ليست اعتماداً علمياً نهائياً؛ يجب أن يراجع المعلم أو المختص المحتوى والمراجع قبل النشر.
