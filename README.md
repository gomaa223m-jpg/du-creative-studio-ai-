# EDU Creative Studio AI — استوديو مستر محمد جمعة التعليمي

منصة تعليمية عربية مجانية بواجهة محلية لإنشاء المحتوى والعروض وأوراق العمل والكتب التفاعلية وتصديرها دون اشتراك أو مفتاح API. يمكن استخدام مزود ذكاء اصطناعي بخطته المجانية عبر نسخ البرومبت يدوياً؛ وتظل حدود المزود المجاني سارية.

## محرك تأليف الكتب الذكي
يتضمن المشروع Worker آمناً لتوليد مخطوطات الكتب وملء محرر الصفحات، مع بحث عن مصادر ومراجعة علمية أولية.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/gomaa223m-jpg/du-creative-studio-ai-)

**لا تحتاج إلى Cloudflare أو مفاتيح API لتشغيل الأدوات المحلية المجانية.** نشر Worker وربط `OPENAI_API_KEY` و`APP_ACCESS_TOKEN` اختياري فقط لمحرك تأليف الكتب السحابي، وقد يترتب عليه استخدام API مدفوع. لا تضع مفاتيح API في ملفات الموقع العامة. راجع [دليل التفعيل](BOOK_ENGINE_SETUP.md) فقط إذا أردت هذا الخيار.

المراجعة الآلية ليست اعتماداً علمياً نهائياً؛ يجب أن يراجع المعلم أو المختص المحتوى والمراجع قبل النشر.

## التكامل مع منصات الذكاء الاصطناعي
أضيفت واجهة API موحدة (REST/OpenAPI) ونقطة MCP عبر HTTP لعملاء MCP المتوافقين. راجع [دليل التكاملات](INTEGRATIONS.md) لمعرفة العناوين والمصادقة وطريقة النشر والاختبار. هذه الواجهات تحتاج نشر Cloudflare Worker وإعداد الأسرار؛ لا يتم تثبيتها تلقائياً في كل منصة.
