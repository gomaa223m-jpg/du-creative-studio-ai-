# EDU CREATIVE STUDIO AI

## الملفات
- index.html: واجهة إنشاء البرومبتات والمحتوى التعليمي.
- api/generate.js: واجهة خادم آمنة للاتصال بـ OpenAI Responses API.
- vercel.json و package.json: إعدادات النشر.

## النشر
يحتاج زر إنشاء المحتوى إلى استضافة تدعم Serverless Functions مثل Vercel. GitHub Pages يستضيف الملفات الثابتة ولا يشغّل دوال Node.js.

1. استورد المستودع إلى مشروع Vercel.
2. لا تضع مفتاح API في GitHub أو HTML.
3. بعد موافقة صاحب الحساب/ولي الأمر على أي إعداد فوترة، أضف OPENAI_API_KEY في Environment Variables داخل الاستضافة فقط.
4. اضبط OPENAI_MODEL على نموذج متاح لحساب API.
5. أعد النشر واختبر الموقع.

## الأمان والتكلفة
- لا ترسل مفتاح API في المحادثات.
- استخدام API منفصل عن اشتراك ChatGPT وقد تترتب عليه رسوم.
- لا تفتح API للعامة قبل إضافة تسجيل دخول وحدود استخدام ومراقبة للتكلفة.
- الطلبات تستخدم store:false. لا تدخل بيانات شخصية أو حساسة للطلاب.

هذه النسخة تولّد نصوصاً تعليمية؛ توليد الصور والفيديو وملفات PowerPoint يحتاج تكاملات إضافية.
